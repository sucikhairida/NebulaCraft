# NebulaCraft

NebulaCraft enables auto-scaling and load-balancing across distributed cloud services, forming a comprehensive video processing suite engine.

With NebulaCraft, you get a lightweight tool that stays out of your way.

**What you get**

- NebulaCraft enables auto-scaling and load-balancing
- across distributed cloud services, forming
- a comprehensive video processing suite

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/NebulaCraft.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure NebulaCraft, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
